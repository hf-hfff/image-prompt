上半区域：完整承载原始参考照片。严格锁定原图所有信息：主体（人物 / 动物 / 花草 / 建筑 / 风景 / 交通工具 / 静物）种类、数量、外轮廓、结构形态、空间位置、服饰配饰、动作姿态、周边环境、构图比例、透视关系、材质肌理、景深、原生光影、整体色调氛围全部保留不变。仅可做高级柔和调色、曝光微调、边缘自然背景延展；严禁主体拉伸扭曲、移位、替换、重绘、新增无关元素。原图满铺填满上半区，顶边、左右两侧直达画布边缘，底边贴合水平分割线，呈现高级艺术杂志纪实摄影质感。
下半区域：仅以上方同一张原图作为唯一参考源，提取主体辨识度最高的轮廓、姿态、空间关系、主色调与视觉重心，重构为流体光栅线条雕塑。
核心逻辑：主体不是轮廓描边、不是色块填充，形态从一整组连续平行的超细柔性曲线体系中生长而出；线条靠近主体区域时顺滑弯折、聚拢，依靠疏密渐变、轻微舒展变化塑造隐式浮雕体积感；远离主体之后回归平直、等距、均匀的平行线场。
线条、主体、负空间属于一套连续统一结构，不存在单独外勾边线、封闭轮廓圈、纯色块、线框模型、实体三维几何体、贴图式附着线条。
线条形态：单根线条两端收尖极细、中段适度加粗，渐变过渡柔和，复刻精密版画刻线特征；粗细变化平缓，杜绝突兀跳变、厚重条纹、机械重复纹理。依靠贝塞尔流体连续弧线、曲率变化塑造全部体积起伏，顺着形体凹凸自然转向；所有尖角、直角、折角、锯齿、硬拐点全部柔化转成顺滑曲线，禁止折线、锐角、大量交叉、线条断裂、杂乱涟漪、无规则形变。
缩放与布局：下半区这套流体线条雕塑整体缩至原尺寸 70%，占用下半区域 20%-35% 面积；摆放位置居中，或跟随原图视觉重心小幅偏移，四周大面积预留暖白 / 奶油白 / 象牙白 / 浅暖灰纸面留白。
线条色彩：从原图提取 1-2 种低饱和度主色，依靠线条疏密、间距、粗细、浓淡变化表达明暗层次；不做写实光影、硬阴影，拒绝金属、塑料、石膏、实体浮雕材质效果。叠加极淡版画颗粒、纸张纤维质感、天然油墨肌理，肌理不能破坏线条锐利精度。
文字排版：留白区域放置少量通顺可读、贴合画面主题的英文主标题 + 简短副标题 + 微型说明文字；禁止序号、乱码、假英文、水印、logo 标识。主标题选用纤细高对比 Didot / Bodoni / Didone 类衬线字体，辅助小字用简约无衬线字体，采用松弛非对称版式排布，文字不能遮挡线条雕塑视觉焦点。
